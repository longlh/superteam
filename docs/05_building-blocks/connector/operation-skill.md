# Operation Skill

The bridge between a prompt and the MCP tools. An actor runs it as a slash
command, or an AI agent loads it on its own. It always goes through the MCP
server.

## Component

No operation skill is made yet: the person uses the tools of the MCP server (see
`mcp-server.md`). Which skills are made is not decided (see
`risks-and-debts.md`).
